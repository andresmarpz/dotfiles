# Keybinds

## Kitty (escape hatch)

| Keybind | Action |
|---------|--------|
| `Ctrl+Cmd+T` | New tab |
| `Ctrl+Cmd+W` | Close tab |
| `Ctrl+Cmd+]` | Next tab |
| `Ctrl+Cmd+[` | Previous tab |
| `Ctrl+Cmd+1-3` | Focus tab 1-3 |

## Tmux

| Keybind | Action |
|---------|--------|
| `Cmd+D` | Detach from session |

### Panes

| Keybind | Action |
|---------|--------|
| `Cmd+\` | Vertical split (side by side) |
| `Cmd+Shift+\` | Horizontal split (stacked) |
| `Cmd+Arrows` | Navigate between panes |
| `Cmd+Shift+Arrows` | Resize panes |
| `Cmd+Shift+Enter` | Zoom pane (toggle fullscreen) |
| `Cmd+W` | Close pane |

### Windows

| Keybind | Action |
|---------|--------|
| `Cmd+1-9` | Switch to window 1-9 |
| `Cmd+Shift+]` | Next window |
| `Cmd+Shift+[` | Previous window |
| `Cmd+T` | New window |
| `Cmd+Shift+R` | Rename window |

### Sessions

| Keybind | Action |
|---------|--------|
| `Cmd+S` | Session picker |
| `Cmd+Shift+N` | New session |

**Inside session picker (`Cmd+S`):**

| Key | Action |
|-----|--------|
| `x` | Kill selected session |
| `Enter` | Switch to selected |
| `q` | Cancel |

### Other

| Keybind | Action |
|---------|--------|
| `Cmd+F` | Enter copy mode |
| `Cmd+K` | Clear screen |

## Fish

| Command | Action |
|---------|--------|
| `dev` | Start dev session in current directory |
| `dev ~/path` | Start dev session at path |
